# happysnaker/.github

Default community health files for happysnaker repositories.

This repository centralizes shared contribution, security, and issue-reporting guidance for public repositories under the `happysnaker` account.

Included here:

- contributing guidance
- security reporting guidance
- flagship project pages and project-specific documentation routes
- default issue / PR templates
- account-wide code of conduct

## Default issue entry

Use the repo-local issue templates first. For private security reports, follow each repository's `SECURITY.md`.

Do not paste private logs, credentials, QR codes, payment screenshots, or internal URLs into public issues.
